Queryable World Model

当前对 NeoVerse 方法及其改进的实验已证明了重建模型提取通用世界表征的潜力，能够很好地达成最初的时空控制目标。然而，如果仅是实现更好的时空控制，叙事仍然停留在应用层，因为时空控制本身只是对模型能力的一种检验。更本质的科学问题应当是：世界模型是否应该构建一种可查询的世界表征？真实世界天然具有时间、空间、相机位姿、几何、语义和状态结构，因此世界模型不应只在给定完整轨迹后顺序生成视频，而应先将 RGB、几何、文本和动态信息压缩为统一的世界表征，再通过时间、空间和状态等进行查询，通过先压缩再查询的方式实现解耦。这样，传统 control 只是 query 的退化形式：给定完整 ((camera_t, time_t)) 轨迹并查询 RGB，就得到可控视频；而更一般的 query 还可以随机访问任意时空位置、任意时间长度，输出 RGB、depth、pointmap、action 或语义状态，甚至只查询局部区域或仅学习表征。
另外，可查询意味着可保存：一旦世界状态可以被时间、相机位姿和空间位置索引，它就可以被缓存、复用并持续约束后续生成，从而自然提升长程一致、时空一致和持续一致。相比直接注入式控制容易污染原始记忆，先压缩再查询能够把持久世界记忆与查询条件分离，进而得到一个可查询、可保存、可持续更新的世界模型。
在上述框架之下，我们能够以崭新的范式统一描述长程、时空可控、动作策略生成等现有的世界模型范式，未来还能继续扩展到与动作相关的世界模型去。
