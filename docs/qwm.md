# Queryable World Memory

## Abstract

World models should not only generate plausible videos, but also expose a persistent representation of the world that can be accessed through space, time, and state. Existing controllable video generation methods often treat camera motion and temporal evolution as conditioning signals for producing a complete output sequence. This formulation has led to strong trajectory-level control, especially when explicit 4D representations are used as an intermediate scene model. However, trajectory control is only one use case of a more general capability: random-access querying of a dynamic world.

We study a queryable world memory formulation for video-based dynamic scene modeling. Given observed visual evidence, the model consolidates appearance, geometry, motion, and optional semantic cues into a compact memory. A query, defined by camera, time, and potentially other state variables, reads from this memory and produces a response in the requested modality, such as RGB, depth, pointmap, action, semantic feature, or a generative latent condition. Under this view, camera-controllable video generation becomes the batched special case where a sequence of camera-time queries is decoded as a video.

As a first instantiation, we focus on camera-time querying for generative video refinement. Unlike rendering-based pipelines that connect 4D reconstruction and video diffusion through degraded RGB, depth, and mask images, our formulation reads reconstruction evidence directly into diffusion-compatible latent conditions. This latent query interface preserves the explicit indexability of 4D scene representations while reducing the information bottleneck introduced by fixed rendering interfaces. It also provides a path toward scalable, end-to-end optimization of reconstruction, memory formation, and generative decoding from in-the-wild videos.

## Introduction

Videos record a world that is structured by space and time. A person moves, objects become occluded and reappear, the camera changes viewpoint, and the same scene state can be observed from different positions. A world model built from video should therefore do more than synthesize a plausible clip. It should organize observed evidence into a representation that can be revisited, inspected, and decoded at arbitrary space-time coordinates. In this sense, queryability is not an auxiliary interface for control; it is a basic property that a dynamic world representation ought to expose.

Most recent work on controllable video generation approaches this problem from the opposite direction. Camera trajectory, temporal order, sparse frames, or text are injected as conditioning signals, and the model is asked to generate an output video that follows these controls. This trajectory-level formulation is useful and has produced impressive systems. It is also a natural evaluation setting: given a path of cameras and timestamps, the model should generate a coherent video. Yet the formulation hides a more general problem. A complete trajectory is simply a batch of queries. If a model can answer arbitrary camera-time queries from a persistent world representation, then controllable video generation follows by querying that representation along a trajectory. The reverse is not necessarily true: a model that generates one controlled sequence need not support sparse, unordered, repeated, or cross-modal access to the same world state.

Explicit 3D and 4D representations make this distinction particularly clear. Methods based on NeRFs, 3D Gaussian Splatting, or dynamic Gaussian scene models already expose space and time as coordinates. A target camera and timestamp can be rendered by querying the representation. This is the main reason that reconstruction-based pipelines are strong baselines for spatiotemporal control. NeoVerse is representative of this line of work: it reconstructs a dynamic 4D scene from an input video, renders degraded RGB, depth, and mask conditions at target camera-time coordinates, and then uses a video diffusion refiner to complete and enhance the result. This design gives clean control over camera and time because the control is grounded in a 4D scene representation.

The strength of this paradigm is also its limitation. The rich output of reconstruction is compressed into a fixed rendering interface before it reaches the generative model. Geometry, visibility, uncertainty, appearance features, temporal correspondences, and reconstruction features are reduced to degraded RGB, depth, and masks. This interface is easy to interpret, but it can discard information that is useful for generative refinement. It also creates a hard boundary between reconstruction and generation: the reconstruction module produces renderable observations, the diffusion model refines them, and the two parts are difficult to optimize jointly beyond this hand-designed interface. As a result, errors from reconstruction, rendering, masking, and refinement can accumulate rather than be resolved through a shared latent representation.

We argue for a different view: first consolidate world evidence into a queryable memory, then decode task-specific responses from this memory. The memory is not merely a rendered image buffer. It is a compressed representation of heterogeneous evidence, including visual appearance, geometry, motion, camera information, and potentially language, semantics, or actions. A query specifies how the world should be accessed. In the simplest case, the query contains a target camera and time. More generally, it may include state variables such as object identity, action, semantic region, or task intent. The response need not be an RGB video. It may be an RGB frame, depth map, pointmap, action prediction, semantic feature, uncertainty estimate, or a latent condition for a generative decoder.

This formulation separates representation from application. Spatiotemporal control is no longer the goal itself; it is the first and most necessary test of whether the representation is indexed by space and time. A model that truly maintains a queryable world memory should support random access, repeated queries, cross-view same-time queries, cross-time same-view queries, and sparse or unordered query sets. These capabilities are not captured by ordinary trajectory control alone. They test whether the model has formed a persistent world state rather than merely generated a visually plausible sequence under a given control signal.

The distinction also clarifies what query can do beyond control. First, query supports modality-flexible decoding: the same memory can be read as RGB, depth, pointmap, semantic feature, action, or latent condition, depending on the requested response. Second, query enables persistent and iterative use: multiple queries can share the same memory, and future extensions can update the memory with newly generated or observed evidence. Third, query naturally extends beyond camera and time to broader state variables, turning camera-time control into a special case of state-indexed world access. Finally, query allows the video generator to be removed entirely when the downstream task only requires representation, geometry, correspondence, or action-relevant features.

Our current implementation instantiates this idea in a focused setting: camera-time latent querying for video generation. We use a frozen or pretrained 4D reconstruction backbone to extract intermediate reconstruction tokens from observed context frames. These tokens form the source evidence memory. Target camera-time queries are encoded from camera pose, intrinsics, Plucker rays, timestamp, and latent-grid position. A cross-attention readout then maps the target queries to diffusion-compatible control latents. In the first training stage, the original rendering-based NeoVerse control branch provides a teacher latent: rendered RGB, depth, mask, and camera conditions are encoded by the teacher, while the student learns to predict the same latent directly from reconstruction memory and camera-time queries. This distillation creates a bridge from reconstruction evidence to generative latents without requiring the student to reproduce the explicit rendering interface.

This design preserves the main advantage of NeoVerse: camera and time remain explicit query axes. At the same time, it changes the communication protocol between reconstruction and generation. Rather than passing through degraded 2D renderings, the generative model receives a latent response read from reconstruction memory. This response can carry information that is not easily represented by RGB, depth, and mask images alone. It also provides a more natural substrate for later end-to-end training, where the memory encoder, query readout, and generative decoder can be optimized under reconstruction, diffusion, and consistency objectives.

The contribution is therefore not simply a better condition encoder for controllable video generation. The broader claim is that dynamic world modeling should be formulated as evidence compression followed by query-based access. Trajectory-level video control is a useful evaluation protocol, but it is a degenerate case of querying a world memory along a path. By making this hierarchy explicit, we can evaluate world models with stronger criteria: whether they support random-access spatiotemporal queries, whether repeated queries return consistent states, whether cross-view and cross-time responses agree, and whether the same memory can serve multiple output modalities.

In summary, the proposed direction reframes spatiotemporal control as a representation problem. The world has space and time; a world model should expose them as indexed axes. A queryable world memory compresses observed evidence into a persistent representation and decodes responses through camera-time-state queries. This perspective keeps the practical strengths of reconstruction-based control while opening a path toward more general, multimodal, and eventually read-write dynamic world models.
